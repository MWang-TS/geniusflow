## 1. 核心概念

| 概念 | 说明 |
|------|------|
| **流程定义 (ProcessDefinition)** | 流程的蓝图，包含节点定义和连线关系。发布后不可变。 |
| **流程实例 (ProcessInstance)** | 流程定义的运行时实体，绑定特定版本。 |
| **节点定义 (NodeDefinition)** | 流程中的单个节点，包含输入/行动/输出三阶段配置。 |
| **节点实例 (NodeInstance)** | 节点定义的运行时实体，记录实际执行数据。 |
| **任务 (Task)** | 分配给具体用户的待办事项，分为执行任务和审批任务。 |

## 2. 节点状态机

### 2.1 状态定义

```
┌──────────┐    实例化      ┌─────────────┐    员工开始    ┌─────────────┐
│ waiting  │ ────────────▶ │ in_progress │ ────────────▶ │  员工执行   │
│  (等待)   │               │  (进行中)    │               │   中...    │
└──────────┘               └─────────────┘               └──────┬──────┘
     ▲                                                          │
     │                    驳回后重新修改                          │ 提交
     │                    ┌─────────────────────────────────────┘
     │                    │
     │               ┌────┴──────────┐
     │               │ ai_inspecting │
     │               │ (AI 校验中)    │
     │               └────┬──────────┘
     │                    │
     │         ┌──────────┴──────────┐
     │         │                     │
     │    督导通过              督导拦截
     │         │                     │
     │         ▼                     ▼
     │  ┌─────────────┐       ┌─────────────┐
     │  │pending_approval│     │ in_progress │
     │  │ (待审批)     │       │ (修改中)    │
     │  └──────┬──────┘       └─────────────┘
     │         │
     │    审批通过
     │         │
     │         ▼
     │  ┌─────────────┐
     └──┤  completed  │
        │  (已完成)   │
        └─────────────┘
```

### 2.2 状态转换规则

| 当前状态 | 触发事件 | 下一状态 | 执行者 | 说明 |
|----------|----------|----------|--------|------|
| waiting | 实例化 | in_progress | 系统 | 流程实例创建后，第一个节点激活 |
| in_progress | 员工提交 | ai_inspecting | 员工 | 触发 AI 督导（异步） |
| ai_inspecting | 督导通过 | pending_approval | AI | 进入审批环节 |
| ai_inspecting | 督导拦截 | in_progress | AI | 员工需修改 |
| ai_inspecting | 超时降级 | pending_approval | AI | 强制校验降级为仅提醒 |
| pending_approval | 审批通过 | completed | 管理者 | 节点完成 |
| pending_approval | 审批驳回 | in_progress | 管理者 | 员工需修改 |
| completed | 下一节点激活 | waiting → in_progress | 系统 | 自动推进 |

### 2.3 状态转换校验

```typescript
class NodeStateMachine {
  private transitions: Record<string, string[]> = {
    'waiting': ['in_progress'],
    'in_progress': ['ai_inspecting'],
    'ai_inspecting': ['pending_approval', 'in_progress'],
    'pending_approval': ['completed', 'in_progress'],
    'completed': [],
    'rejected': ['in_progress']  // 终止状态的节点
  };

  canTransition(from: string, to: string): boolean {
    return this.transitions[from]?.includes(to) ?? false;
  }

  transition(nodeInstance: NodeInstance, to: string, actor: User): void {
    if (!this.canTransition(nodeInstance.status, to)) {
      throw new StateTransitionError(
        `非法状态转换: ${nodeInstance.status} -> ${to}`
      );
    }
    
    const from = nodeInstance.status;
    nodeInstance.status = to;
    
    // 记录历史
    this.historyService.record({
      nodeInstanceId: nodeInstance.id,
      eventType: this.getEventType(from, to),
      actorUserId: actor.id,
      fromStatus: from,
      toStatus: to
    });
  }
}
```

### 3.2 节点推进逻辑

```typescript
class ProcessEngine {
  async completeNode(nodeInstanceId: string, approver: User): Promise<void> {
    const nodeInstance = await this.getNodeInstance(nodeInstanceId);
    const processInstance = await this.getProcessInstance(nodeInstance.instanceId);
    
    // 1. 标记当前节点完成
    await this.nodeStateMachine.transition(
      nodeInstance, 
      'completed', 
      approver
    );
    
    // 2. 查找下一个节点
    const nextNodeDef = await this.findNextNode(nodeInstance);
    
    if (!nextNodeDef) {
      // 无下一节点，流程完成
      await this.completeProcess(processInstance);
      return;
    }
    
    // 3. 创建下一节点实例
    const nextNodeInstance = await this.createNodeInstance(
      processInstance,
      nextNodeDef
    );
    
    // 4. 更新流程当前节点
    processInstance.currentNodeId = nextNodeInstance.id;
    await this.processInstanceRepo.save(processInstance);
    
    // 5. 激活下一节点
    await this.activateNode(nextNodeInstance);
  }

  private async findNextNode(currentNode: NodeInstance): Promise<NodeDefinition | null> {
    // MVP 线性顺序：按 sort_order 查找下一个
    const nodes = await this.nodeDefRepo.findByProcessId(
      currentNode.processId,
      { orderBy: 'sort_order' }
    );
    
    const currentIndex = nodes.findIndex(n => n.id === currentNode.definitionId);
    return nodes[currentIndex + 1] ?? null;
  }
}
```

### 3.3 流程终止

```typescript
async terminateProcess(instanceId: string, reason: string, operator: User): Promise<void> {
  const instance = await this.getProcessInstance(instanceId);
  
  if (instance.status !== 'running') {
    throw new Error('只能终止进行中的流程');
  }
  
  // 1. 更新流程状态
  instance.status = 'terminated';
  await this.processInstanceRepo.save(instance);
  
  // 2. 取消所有待办任务
  await this.taskRepo.cancelByProcessInstance(instanceId);
  
  // 3. 取消所有进行中节点的任务
  const activeNodes = await this.nodeInstanceRepo.findByInstanceAndStatus(
    instanceId, 
    ['in_progress', 'ai_inspecting', 'pending_approval']
  );
  
  for (const node of activeNodes) {
    await this.nodeStateMachine.transition(node, 'rejected', operator);
  }
  
  // 4. 记录审计日志
  await this.auditLogService.record({
    userId: operator.id,
    action: 'process.terminate',
    resourceType: 'process_instance',
    resourceId: instanceId,
    details: { reason }
  });
}
```

### 4.2 AI 督导异步处理

```typescript
class AIInspectionJob {
  async process(job: Job<AIInspectionPayload>): Promise<void> {
    const { nodeInstanceId } = job.data;
    const nodeInstance = await this.getNodeInstance(nodeInstanceId);
    
    try {
      // 1. 获取节点配置
      const nodeDef = await this.getNodeDefinition(nodeInstance.definitionId);
      const aiConfig = nodeDef.aiConfig.inspector;
      
      // 2. 检索知识库
      const chunks = await this.ragService.retrieve(
        this.buildQuery(nodeInstance),
        aiConfig.knowledgeBaseId
      );
      
      // 3. 调用 AI 督导
      const result = await this.aiService.inspect({
        nodeName: nodeDef.nodeName,
        inputData: nodeInstance.inputData,
        outputData: nodeInstance.outputData,
        acceptanceCriteria: nodeDef.inputSpec.acceptanceCriteria,
        qualityStandard: nodeDef.outputSpec.qualityStandard,
        knowledgeBaseChunks: chunks
      });
      
      // 4. 保存 AI 报告
      await this.aiReportRepo.save({
        nodeInstanceId,
        reportType: 'inspector',
        content: result
      });
      
      // 5. 根据结果更新状态
      if (result.passed) {
        await this.nodeStateMachine.transition(
          nodeInstance, 
          'pending_approval', 
          SYSTEM_USER
        );
        
        // 6. 创建审批任务
        await this.createApprovalTask(nodeInstance);
        
        // 7. 通知审批人
        await this.notificationService.send({
          userId: nodeInstance.responsibleRoleId,
          title: '新审批任务',
          content: `...`
        });
      } else {
        await this.nodeStateMachine.transition(
          nodeInstance, 
          'in_progress', 
          SYSTEM_USER
        );
      }
      
      // 8. WebSocket 推送结果
      await this.wsService.emit(nodeInstance.assigneeUserId, {
        type: 'ai_inspection_result',
        payload: { nodeInstanceId, result }
      });
      
    } catch (error) {
      // 超时或异常：降级处理
      await this.handleInspectionFallback(nodeInstance, error);
    }
  }
  
  private async handleInspectionFallback(
    nodeInstance: NodeInstance, 
    error: Error
  ): Promise<void> {
    // 记录降级日志
    await this.aiAgentLogRepo.save({
      nodeInstanceId: nodeInstance.id,
      role: 'inspector',
      isFallback: true,
      errorMessage: error.message
    });
    
    // 降级为仅提醒，允许提交
    await this.nodeStateMachine.transition(
      nodeInstance, 
      'pending_approval', 
      SYSTEM_USER
    );
    
    await this.createApprovalTask(nodeInstance);
    
    // 通知员工和管理者
    await this.wsService.emit(nodeInstance.assigneeUserId, {
      type: 'ai_inspection_result',
      payload: {
        nodeInstanceId: nodeInstance.id,
        result: null,
        warning: 'AI 校验超时，已降级处理',
        isFallback: true
      }
    });
  }
}
```

## 6. 进度计算

### 6.1 节点计划时间推算

```typescript
class ProgressCalculator {
  calculateNodeSchedule(
    processInstance: ProcessInstance,
    nodeDefs: NodeDefinition[]
  ): NodeSchedule[] {
    const baseDate = processInstance.plannedStartDate;
    let currentDate = new Date(baseDate);
    
    return nodeDefs.map(def => {
      const duration = def.progressConfig.plannedDuration || 1;
      
      const schedule = {
        definitionId: def.id,
        plannedStartDate: new Date(currentDate),
        plannedEndDate: this.addBusinessDays(currentDate, duration)
      };
      
      currentDate = schedule.plannedEndDate;
      return schedule;
    });
  }
  
  // 只算工作日
  private addBusinessDays(date: Date, days: number): Date {
    const result = new Date(date);
    let added = 0;
    while (added < days) {
      result.setDate(result.getDate() + 1);
      if (result.getDay() !== 0 && result.getDay() !== 6) {
        added++;
      }
    }
    return result;
  }
}
```

### 7.2 流程定义编辑锁

```typescript
class ProcessDefinitionLock {
  // Redis 分布式锁，防止多人同时编辑草稿
  async acquireLock(definitionId: string, userId: string): Promise<boolean> {
    const key = `process_def_lock:${definitionId}`;
    const acquired = await this.redis.set(key, userId, 'EX', 300, 'NX');
    return acquired === 'OK';
  }
  
  async releaseLock(definitionId: string, userId: string): Promise<void> {
    const key = `process_def_lock:${definitionId}`;
    const current = await this.redis.get(key);
    if (current === userId) {
      await this.redis.del(key);
    }
  }
}
```
