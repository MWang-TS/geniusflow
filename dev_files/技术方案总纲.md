## 2. 核心设计原则

### 2.1 确定性流程引擎

- 流程定义发布后**不可变**
- 流程实例严格绑定**创建时的流程版本**
- 节点状态转换由**状态机**驱动，不允许非法跳转

### 2.2 AI 异步非阻塞

- 督导校验**异步执行**，不阻塞员工提交操作
- AI 服务与主服务**解耦**，通过消息队列通信
- AI 超时**自动降级**，保证系统可用性

### 2.3 单租户简化

- MVP 阶段**单租户部署**
- 不实现租户隔离逻辑
- 用户/角色表预留，但不关联租户

## 4. 非功能需求实现

| 需求 | 实现方案 |
|------|----------|
| 100 并发流程实例 | NestJS 异步非阻塞 + PostgreSQL 连接池 |
| 流程加载 < 1s | Redis 缓存流程定义 + 数据库索引优化 |
| 节点提交 < 0.5s | AI 异步执行，提交接口只写数据库 |
| AI 调用超时 10s | Bull 队列 + 超时降级 |
| 可用性 99.5% | 单实例部署 + 健康检查 + 自动重启 |
| 单租户数据隔离 | 单租户部署，无多租户逻辑 |
| 操作日志 6 个月 | audit_logs 表 + 定时清理任务 |
