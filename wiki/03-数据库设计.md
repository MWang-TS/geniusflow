# 数据库设计

数据库采用 **PostgreSQL 16**，通过 **pgvector** 扩展支持向量相似度搜索。ORM 层使用 **Prisma 5**。

---

## 一、实体关系总览

```
用户认证域
  User ←→ UserRole ←→ Role

流程设计域
  ProcessDefinition → NodeDefinition
  ProcessDefinition → Template (模板市场)

流程执行域
  ProcessInstance → NodeInstance → NodeInstanceHistory
  NodeInstance → Task（审批任务）
  NodeInstance → AiAgentLog（AI 巡检日志）
  ProcessInstance/NodeInstance → AiReport（AI 报告）

知识库域
  KnowledgeBase → KnowledgeBaseDocument → DocumentChunk（含 vector 列）

AI 配置域
  AiProvider → AiModel → ModelFallbackChain
  AgentSkill ←→ AgentRoleSkill ←→ AgentRole

系统域
  AuditLog（审计日志）
  Notification（站内通知）
```

## 二、各表详细说明

### 2.1 User（用户）

| 列名 | 类型 | 说明 |
|------|------|------|
| id | String (cuid) | 主键 |
| email | String | 唯一，登录账号 |
| password | String | bcrypt 哈希 |
| name | String | 显示名称 |
| isActive | Boolean | 是否激活，默认 true |
| refreshToken | String? | 当前 refresh token 哈希 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

关联：`UserRole[]`（多角色）

---

### 2.2 Role（角色）

| 列名 | 类型 | 说明 |
|------|------|------|
| id | String (cuid) | 主键 |
| name | String | 唯一，角色标识符 |
| description | String? | 描述 |
| permissions | Json | 权限配置（JSON） |

内置角色：`admin`、`designer`、`manager`、`employee`

---

### 2.3 UserRole（用户角色关联）

### 2.14 DocumentChunk（文档分块）

| 列名 | 类型 | 说明 |
|------|------|------|
| id | String (cuid) | 主键 |
| documentId | String | 所属文档 |
| content | String | 文本内容 |
| embedding | Unsupported("vector(1536)") | 向量嵌入，1536 维 |
| chunkIndex | Int | 分块序号 |
| metadata | Json? | 额外元数据 |
| createdAt | DateTime | 时间戳 |

> 向量使用 `text-embedding-3-small` 模型生成，维度 1536。pgvector 通过 cosine 距离进行相似度检索。
