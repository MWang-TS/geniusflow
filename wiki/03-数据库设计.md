# 数据库设计

数据库采用 **PostgreSQL 16**，通过 **pgvector** 扩展支持向量相似度搜索。ORM 层使用 **Prisma 5**。

---

## 一、实体关系总览

```
用户认证域
  User ←→ UserRole ←→ Role

流程设计域
  ProcessDefinition → NodeDefinition

流程执行域
  ProcessInstance → NodeInstance → NodeInstanceHistory
  NodeInstance → Task（审批任务）
  NodeInstance → AiAgentLog（AI 巡检日志）
  NodeInstance → AiReport（AI 质量报告）

RAG 知识库域
  KnowledgeBase（mode=rag）→ KnowledgeBaseDocument → DocumentChunk（含 vector 列）

Wiki 知识库域
  KnowledgeBase（mode=wiki）→ WikiRawSource（原始文件）
  KnowledgeBase → WikiPage（结构化页面）
  KnowledgeBase → WikiTriple（知识图谱三元组）

AI 配置域
  AiProvider → AiModel → ModelFallbackChain
  AgentSkill ←→ AgentRoleSkill ←→ AgentRole

系统域
  AuditLog（审计日志）
  Notification（站内通知）
  ApiKey（开放平台密鉅）
  SystemConfig（系统配置 KV 表）
```

## 二、各表详细说明

### 2.1 User（用户）

| 列名 | 类型 | 说明 |
|------|------|------|
| id | String (uuid) | 主键 |
| email | String | 唯一，登录账号 |
| passwordHash | String | bcrypt 哈希（字段实际为 `password_hash`） |
| name | String | 显示名称 |
| status | String | `active` / `inactive`，默认 `active` |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

关联：`UserRole[]`（多角色）、`Task[]`、`NodeInstance[]`、`ProcessInstance[]`、`ApiKey[]`

---

### 2.2 Role（角色）

| 列名 | 类型 | 说明 |
|------|------|------|
| id | String (uuid) | 主键 |
| name | String | 唯一，角色标识符 |
| description | String? | 描述 |
| permissions | Json | 权限配置（JSON 数组） |
| routePermissions | Json | 路由权限配置（JSON 数组） |

内置角色：`admin`、`designer`、`manager`、`employee`

### 2.14 DocumentChunk（文档分块）

| 列名 | 类型 | 说明 |
|------|------|------|
| id | String (uuid) | 主键 |
| documentId | String | 所属文档 |
| chunkIndex | Int | 分块序号 |
