# 项目概览

## 一、产品定位

GeniusFlow 是一个**智能业务流程管理平台**，核心理念是将 AI 能力嵌入流程的每个执行节点，实现：

- **质量自动巡检**：AI 督导员在节点提交后自动对比验收标准，输出质量报告
- **智能审批辅助**：AI 助理为管理层生成结构化的审批建议（通过/拒绝 + 置信度 + 风险分析）
- **知识库增强**：节点巡检时可关联企业知识库，引用规范文档作为参考
- **可视化流程设计**：基于 React Flow 的拖拽式画布，支持流程模板市场

## 二、功能模块

### 2.1 流程设计

| 功能 | 说明 |
|------|------|
| 流程定义管理 | 创建、编辑、发布、归档流程定义 |
| 可视化编辑器 | 拖拽节点、连线，配置每个节点的输入/输出规范和 AI 参数 |
| 模板市场 | 预置流程模板，支持一键复制并进入编辑 |
| 版本控制 | 流程名称+版本唯一约束，发布后不可修改（需新版本） |

### 2.2 流程执行

| 功能 | 说明 |
|------|------|
| 流程实例 | 基于已发布流程创建执行实例，支持计划时间设定 |
| 节点执行 | 执行人填写节点输出数据，保存草稿或提交 |
| AI 巡检 | 提交后异步触发 AI Inspector，生成质量报告 |
| 进度看板 | Gantt 图展示各节点计划/实际时间轴 |

### 2.3 审批工作流

| 功能 | 说明 |
|------|------|
| 审批任务 | 节点提交后自动创建审批任务，分配给责任人 |
| AI 辅助审批 | AI Assistant 生成审批建议，辅助管理者决策 |
| 审批记录 | 完整审批历史，支持拒绝并附原因 |

### 2.4 知识库

| 功能 | 说明 |
|------|------|
| 知识库管理 | 创建分类知识库（标准/规程/案例等） |
| 文档上传 | 支持 TXT、PDF、DOCX 等格式，异步解析+向量化 |
| 语义检索 | 向量相似度搜索，在 AI 巡检时自动关联相关片段 |

### 2.5 AI 助理模式

| 功能 | 说明 |
|------|------|
| 技能对话 | 选择 Agent 角色和知识库，进行流式对话 |
| Function Calling | Agent 自动调用注册的工具技能（检索/API调用/代码执行） |
| 工具状态展示 | 对话界面实时展示当前正在调用的工具名称 |
| 流式输出 | SSE 流式返回，一字一字展示回复 |
| 历史上下文 | 自动携带对话历史作为上下文 |

### 2.6 AI 中台模式

| 功能 | 说明 |
|------|------|
| API 密钥管理 | 创建、查看、删除 OpenAPI 密钥 |
| 密钥绑定 | 每个密钥可绑定指定 Agent 角色和知识库 |
| 过期时间 | 支持设定密钥过期日期 |
| 接口一覆性 | 同一密钥可对接所有支持 Function Calling 的工具调用 |

### 2.7 模板市场

| 功能 | 说明 |
|------|------|
| 卡片布局 | 模板以卡片网格展示，展示名称、描述、节点数和日期 |
| 职能线筛选 | 支持按职能线（全部/市场/投标/销售/研发/项目管理等 16 个选项）筛选 |
| 关键词搜索 | 按模板名称或描述进行模糊搜索 |
| 一键复制 | 点击复制到我的流程，自动跳转到流程编辑器 |
| 全模式可见 | 模板市场在全部三种平台模式（流程/助理/中台）的侧边栏均可访问 |

### 2.8 AI 配置（管理员）

| 功能 | 说明 |
|------|------|
| AI 提供商 | 管理 OpenAI / Anthropic / Ollama / Azure 等提供商的连接信息 |
| 模型管理 | 配置对话模型、嵌入模型，设定默认模型 |
| Fallback 链 | 为每种模型类型配置有序备用链，主模型失败时自动切换 |
| Agent 技能 | 定义 Agent 可调用的工具/检索/代码执行技能（支持 Function Calling） |
| Agent 角色 | 配置 Agent 角色的系统提示词、绑定模型和技能 |
| 全量导出 | 一键导出所有 AI 配置（提供商/模型/技能/角色/Fallback）为 JSON |
| 全量导入 | 上传 JSON 文件一键恢复所有 AI 配置 |

### 2.9 系统管理

| 功能 | 说明 |
|------|------|
| 用户管理 | 用户 CRUD，支持激活/停用 |
| 角色权限 | 角色定义与权限分配（admin / designer / manager / employee） |
| 审计日志 | 记录所有关键操作，含操作人、IP、时间 |
| 实时通知 | WebSocket 推送 + 站内消息，支持逾期自动扫描提醒 |

## 三、技术栈

### 后端 `api/`

| 技术 | 版本 | 用途 |
|------|------|------|
| NestJS | 10.x | 主框架，模块化 IoC |
| Prisma | 5.x | ORM，类型安全数据库操作 |
| PostgreSQL + pgvector | 16 | 关系数据存储 + 向量相似度搜索 |
| Redis + Bull | 7 / 4.x | 消息队列，异步 AI 任务 |
| Socket.IO | 4.x | WebSocket 实时通知 |
| JWT + Passport | — | 认证鉴权 |
| class-validator | 0.14 | 请求参数校验 |
| @nestjs/schedule | 6.x | 定时任务（逾期扫描） |

### 前端 `web/`

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18 | UI 框架 |
| Vite | 5 | 构建工具 |
| TypeScript | 5 | 类型安全 |
| Ant Design | 5 | UI 组件库 |
| @xyflow/react (React Flow) | 12 | 流程编辑器画布 |
| Zustand | 4 | 轻量状态管理 |
| TanStack Query | 5 | 服务端状态管理（部分接口） |
| Axios | 1.6 | HTTP 客户端 |
| Socket.IO Client | 4 | WebSocket 客户端 |
| React Router | 6 | 路由管理 |

### AI 服务 `ai-service/`

| 技术 | 版本 | 用途 |
|------|------|------|
| FastAPI | — | Python Web 框架 |
| OpenAI SDK | — | 调用 LLM 和嵌入模型 |
| pydantic-settings | — | 配置管理 |
| asyncpg / psycopg | — | 向量检索查询 |
