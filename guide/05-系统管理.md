# 系统管理

> 适用角色：系统管理员

系统管理功能位于左侧菜单底部的**管理后台**，仅管理员角色可见。

---

## 一、用户管理

进入 **管理后台 → 用户管理**。

### 1.1 用户列表

表格展示所有用户，字段包括：
- 用户名、邮箱
- 状态：正常（绿色）/ 禁用（红色）
- 分配的角色（标签形式）
- 创建时间

### 1.2 创建用户

1. 点击 **「新建用户」**
2. 填写：
   - **用户名**
   - **邮箱**（用于登录）
   - **初始密码**
   - **状态**：正常 / 禁用
   - **分配角色**（多选）
3. 点击确认

> 用户首次登录后应自行修改密码。

### 1.3 编辑用户

点击用户右侧 **「编辑」** 按钮，可修改：
- 用户名、邮箱
- 启用/禁用状态
- 角色分配

### 1.4 禁用用户

编辑用户时将状态改为**禁用**，该用户将无法登录。

### 1.5 删除用户

点击 **「删除」** 并确认。删除后数据不可恢复，请谨慎操作。

---

## 二、角色管理

进入 **管理后台 → 角色管理**，管理角色及其页面访问权限。

### 2.1 内置角色

系统预设以下角色：

| 角色 | 说明 |
|------|------|
| `admin` | 系统管理员，拥有所有权限 |
| `designer` | 流程设计者，可创建和发布流程 |
| `manager` | 管理者，可审批和查看进度 |
| `employee` | 执行员工，可执行任务 |

### 2.2 创建自定义角色

1. 点击 **「新建角色」**
2. 输入角色名称和描述
3. 点击确认创建

### 2.3 配置角色权限（路由权限）

1. 点击角色右侧 **「配置权限」**
2. 右侧抽屉展开，显示所有可配置的页面路由
3. 勾选该角色可访问的页面
4. 保存后生效

> 分配该角色的用户下次刷新后，菜单会自动更新。

### 2.4 查看角色成员

点击 **「查看成员」**，显示当前拥有该角色的所有用户。

### 2.5 编辑 / 删除角色

- **编辑**：修改角色名称和描述
- **删除**：删除角色后，已分配该角色的用户将失去对应权限

---

## 三、AI 配置

进入 **管理后台 → AI 配置**，管理平台的 AI 模型和 Agent 设置。

该页面分为 7 个选项卡：

---

### 3.1 AI 提供商

管理 AI 服务提供商（OpenAI、Azure OpenAI、Claude、通义千问、DeepSeek 等兼容 OpenAI 格式的服务）。

**添加提供商：**
1. 点击 **「新增提供商」**
2. 填写：
   - 提供商名称
   - API Key
   - Base URL（国内代理或自定义服务填写此项）
3. 保存

---

### 3.2 对话模型管理

基于提供商，配置用于**对话和问答**的 LLM 模型。

**添加模型：**
1. 选择关联的提供商
2. 填写模型 ID（如 `gpt-4o`、`deepseek-chat`）
3. 设置模型名称（展示用）
4. 保存

---

### 3.3 知识库模型管理

配置用于**文档向量化**的 Embedding 模型。

> 通常使用 `text-embedding-3-small`（OpenAI）或其他兼容的 Embedding 模型。

---

### 3.4 Fallback 链

配置模型故障转移策略：当主模型请求失败时，自动切换到备用模型。

**配置步骤：**
1. 选择主模型
2. 按优先级添加备用模型
3. 保存 Fallback 链

---

### 3.5 Agent 技能

注册 Agent 可以调用的**工具技能**，扩展 AI 的能力边界。

每个技能包括：
- 技能名称和描述（AI 根据描述决定何时调用）
- 技能参数定义（JSON Schema 格式）
- 技能接口地址

---

### 3.6 Agent 角色

定义 AI 助手的**角色和行为准则**。

**创建角色：**
1. 点击 **「新增角色」**
2. 填写：
   - 角色名称（如：财务顾问、HR 助手）
   - 角色描述（展示给用户）
   - 系统提示词（System Prompt，定义 AI 的行为边界）
   - 关联技能（选择该角色可使用的技能）
3. 保存

---

### 3.7 MinerU 文档解析

配置 MinerU 服务用于高精度文档解析（适用于复杂 PDF、表格等）。

填写 MinerU 服务的 API Key 和服务地址后保存。

---

### 3.8 配置导入导出

页面右上角提供**导入/导出**功能，用于迁移或备份 AI 配置：

**导出：**
- 点击 **「导出配置」**
- 将全部提供商、模型、技能、角色配置（含 API Key）导出为 JSON 文件
- 请妥善保管，文件包含敏感信息

**导入：**
- 点击 **「导入配置」**，选择 JSON 文件
- 系统按名称合并，不会删除现有数据
- 导入完成后显示统计（新增了多少提供商、模型、技能等）

> 适用场景：新环境快速初始化、开发/生产环境配置同步。

---

## 四、通知中心

进入 **通知中心**，查看系统消息和任务提醒。

- **未读通知**：蓝色背景高亮，带 NEW 标签
- **标记已读**：点击单条通知的「标记已读」
- **全部已读**：点击顶部「全部已读」批量处理
- **通知类型**：延期预警（任务超期）、系统通知
