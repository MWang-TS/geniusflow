## 一、AI 技能助手

> 平台模式：AI 助理模式 | 路径：`/skill-assistant`

AI 技能助手是基于企业知识库的智能对话界面，支持多轮对话、知识检索和工具调用。

### 1.1 界面布局

```
┌──────────────────┬──────────────────────────────────────┐
│   左侧配置面板    │           右侧对话区域               │
│                  │                                      │
│  Agent 角色选择  │   [AI 消息]                          │
│  知识库多选      │   [用户消息]                         │
│                  │   [AI 消息]  ...                     │
│                  ├──────────────────────────────────────┤
│                  │  输入框（Enter 发送）         [发送]  │
└──────────────────┴──────────────────────────────────────┘
```

### 1.2 配置对话参数

开始对话前，在左侧面板配置：

**选择 Agent 角色**
- 从下拉框选择一个 Agent 角色
- 每个角色有不同的专业定位和行为准则（由管理员在 AI 配置中定义）

**选择知识库**（可多选）
- 勾选一个或多个知识库
- AI 回答时会从选中的知识库中检索相关内容
- 同时支持 RAG 知识库和 Wiki 知识库

### 1.3 开始对话

1. 在底部输入框输入问题
2. 按 **Enter** 发送（Shift+Enter 换行）
3. AI 以流式方式逐字返回回答
4. 若 AI 正在调用工具，会显示「正在调用工具：xxx」提示
5. 支持随时点击 **「停止」** 中断生成

### 1.4 对话功能特点

- **多轮对话**：AI 会记住本次对话的上下文
- **Markdown 渲染**：AI 回答支持表格、代码块、列表等格式
- **知识溯源**：基于知识库的回答会引用相关文档内容
- **工具调用**：Agent 可调用注册的技能工具执行特定操作
- **清空对话**：点击 **「清空」** 按钮重置对话历史，重新开始

## 二、开放平台（AI 中台模式）

> 平台模式：AI 中台模式 | 路径：`/api-platform`

开放平台允许你创建 API 密钥，供内部其他系统或第三方服务集成调用 GeniusFlow 的 AI 能力。

### 2.1 创建 API 密钥

1. 点击 **「新建密钥」**
2. 填写密钥信息：
   - **密钥名称**：便于识别用途（如：CRM系统集成、钉钉机器人）
   - **关联知识库**（多选）：该密钥可访问哪些知识库
   - **关联 Agent 角色**（单选）：该密钥使用哪个 Agent 角色
   - **过期时间**：设置密钥有效期
3. 点击确认，系统**一次性显示完整密钥**
4. 立即复制保存，关闭弹窗后无法再次查看

> ⚠️ **重要**：密钥只显示一次，请立即复制保存到安全的地方。

### 2.2 管理已有密钥

密钥列表展示：
- 密钥名称
- 关联的知识库（标签形式）
- 关联的 Agent 角色
- 创建时间 / 过期时间

**操作：**
- **复制密钥 ID**：复制密钥标识符
- **删除**：删除后该密钥立即失效，无法恢复

### 2.3 调用 API

获取密钥后，按页面提供的**接口文档**调用：

**请求示例：**
```http
POST /api/v1/open/chat
Authorization: Bearer <your-api-key>
Content-Type: application/json

{
  "message": "你好，请介绍一下产品功能",
  "conversationId": "optional-session-id"
}
```

页面中提供完整的接口说明、请求格式和代码示例，直接参考即可。

## 三、AI 在流程中的应用

除了独立的 AI 功能模块，AI 能力还深度集成在流程执行过程中：

### 3.1 节点 AI 质检

流程设计者可以为任务节点配置 AI 质检规则：
- 任务执行完成后，自动触发 AI 审查
- AI 根据规则检查输出内容的质量和合规性
- 质检结果实时推送给执行人（WebSocket）
- 审批人可查看 AI 质检报告辅助决策

### 3.2 节点 AI 辅助

任务节点可挂载知识库，执行任务时：
- AI 自动召回相关知识库内容
- 在任务执行界面右侧展示参考资料
- 帮助执行人快速获取所需信息

### 3.3 AI 审批摘要

审批节点会自动生成 AI 审批摘要：
- 汇总任务执行情况
- 标注关键风险点
- 辅助审批人快速做出判断
