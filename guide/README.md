## 平台三大模式概览

```
GeniusFlow
├── 流程任务模式   ──  设计流程 → 创建实例 → 执行任务 → 审批 → 进度监控
├── AI 助理模式   ──  选择 Agent → 挂载知识库 → 多轮对话
└── AI 中台模式   ──  管理 API 密钥 → 第三方系统集成调用
```
