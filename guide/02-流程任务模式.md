# 流程任务模式

流程任务模式是 GeniusFlow 的核心使用场景，覆盖从**设计流程**到**执行任务**的完整业务闭环。

---

## 一、流程设计

> 适用角色：流程设计者

### 1.1 查看流程列表

进入 **流程管理 → 流程设计**，可以看到所有流程定义，支持：
- 按名称关键词搜索
- 按状态筛选：草稿 / 已发布 / 已停止 / 已归档

**流程状态说明：**

| 状态 | 含义 |
|------|------|
| 草稿 | 正在编辑中，可修改，不可创建实例 |
| 已发布 | 可创建实例运行，不可再编辑 |
| 已停止 | 停止接受新实例 |
| 已归档 | 归档备查 |

### 1.2 创建新流程

1. 点击右上角 **「新建流程」**
2. 输入流程名称，进入**流程编辑器**

### 1.3 流程编辑器

编辑器分为三个区域：

```
┌──────────────┬──────────────────────────────┬───────────────────┐
│  左侧节点库  │         中央画布              │   右侧属性面板     │
│              │   （拖拽编排节点）            │   （配置选中节点） │
└──────────────┴──────────────────────────────┴───────────────────┘
```

**节点类型：**

| 节点 | 用途 |
|------|------|
| **开始** | 流程起点，每个流程必须有且只有一个 |
| **任务** | 需要人工执行的工作节点，可挂载 AI Agent |
| **审批** | 需要审批人审核通过才能继续的节点 |
| **结束** | 流程终点 |

**配置节点：**
- 在画布上点击选中节点，右侧面板展开属性配置
- 任务节点可配置：节点名称、默认执行人、AI 辅助规则、输入/输出字段
- 审批节点可配置：审批人、审批规则

**连接节点：**
- 将鼠标悬停在节点边缘，出现连接点后拖拽到目标节点

### 1.4 发布流程

1. 编辑完成后点击顶部 **「保存」** 保存草稿
2. 确认无误后点击 **「发布」**，系统验证流程完整性
3. 发布后流程变为只读，可开始创建实例运行

> **注意**：已发布的流程无法再编辑。若需修改，建议复制后新建版本。

## 二、模板市场

> 适用角色：流程设计者

进入 **模板市场**，浏览系统预置的行业流程模板：

- 支持按**职能线**筛选：市场、投标、销售、研发、项目管理等 16 个分类
- 支持按**名称/描述**关键词搜索
- 每页显示 12 个模板，可调整为 24 / 48 个

**使用模板：**
1. 找到合适的模板，点击 **「复制到我的流程」**
2. 系统自动创建副本并打开流程编辑器
3. 在此基础上按需修改后发布

---

## 三、SOP 生成器

> 适用角色：流程设计者

通过自然语言描述，让 AI 自动生成流程结构。

**操作步骤：**

1. 进入 **SOP 生成器**
2. 填写生成参数：
   - **流程描述**：用自然语言描述你的业务流程
   - **所属领域**：选择最接近的领域（软件研发 / 市场营销 / 采购等）
   - **预期步骤数**：估计流程节点数量（默认 6）
   - **角色提示**：添加参与角色标签，帮助 AI 理解（如：项目经理、开发工程师）
   - **辅助文档**（可选）：上传 .txt / .md / .pdf / .docx 文件作为参考材料
3. 点击 **「生成」**，AI 流式返回节点和连接，实时渲染在画布中
4. 查看生成结果，满意后输入流程名称点击 **「保存为流程」**
5. 保存成功后自动跳转至流程编辑器，可进一步调整

---

## 四、创建流程实例

> 适用角色：流程设计者、管理者

流程发布后，需要**创建实例**才能实际运行。

**操作步骤：**

1. 进入 **流程管理 → 流程实例**，点击 **「新建实例」**
2. 选择要运行的**流程定义**（已发布的流程）
3. 为每个**任务节点分配执行人**（必填）
4. 设置**计划开始日期**
5. 点击 **「创建」**，实例开始运行，对应任务分配给相关执行人

## 五、我的任务

> 适用角色：执行员工

进入 **我的任务**，查看分配给自己的所有待办任务。

### 5.1 任务视图

支持两种视图切换：

- **看板视图**：按状态分列展示（待执行 → 执行中 → 已完成 → 已取消），支持拖拽移动
- **列表视图**：表格形式，支持排序

### 5.2 筛选任务

- 按**任务类型**：SOP 执行任务 / 审批确认任务
- 按**状态**：待处理 / 进行中 / 已完成 / 已取消
- 按**执行人**（管理者可查看他人任务）

**任务状态颜色：**

| 状态 | 颜色 |
|------|------|
| 待处理 | 橙色 |
| 进行中 | 蓝色 |
| 已完成 | 绿色 |
| 已取消 | 灰色 |

### 5.3 执行任务

1. 点击任务卡片进入**任务执行页面**
2. 查看任务说明、输入字段要求
3. 填写工作内容和输出数据
4. 如有 AI 质检配置，提交后系统自动触发 AI 审查
5. AI 质检通过或人工确认后，点击 **「完成任务」**
6. 任务完成后自动触发下一节点

> **AI 实时辅助**：任务执行页面会实时推送 AI 质检结果（WebSocket），帮助你在提交前发现问题。

## 六、审批中心

> 适用角色：管理者、审批人

进入 **流程管理 → 审批中心**，处理需要你审批的任务。

### 6.1 查看待审批任务

默认显示**待审批**状态的任务，可切换查看**已处理**记录。

表格字段：流程名称、节点名称、状态、截止日期、创建时间

### 6.2 审批操作

1. 点击任务进入**审批详情页**
2. 查看任务内容和 AI 审查意见（如有）
3. 选择操作：
   - **通过**：可填写备注（默认"同意通过"），点击确认
   - **驳回**：必须填写驳回原因，不可为空
4. 操作完成后自动返回列表

---

## 七、进度监控

> 适用角色：管理者

进入 **流程管理 → 进度监控**，用甘特图可视化掌握流程进度。

### 7.1 实例列表

- 默认展示**运行中**的实例，可切换查看已终止、已完成
- 显示字段：流程名称、状态、节点数、计划/实际开始日期、创建人

### 7.2 甘特图详情

点击实例的 **「甘特」** 按钮进入详情页：

- **整体进度**：已完成节点数 / 总节点数，百分比展示
- **甘特图**：
  - X 轴为时间维度
  - Y 轴为各任务节点
  - 柱条颜色区分状态（完成 / 进行中 / 未开始）
  - 支持缩放和时间区间调整

### 7.3 终止实例

在实例列表，对**运行中**的实例点击 **「终止」** 可强制结束该流程实例。

> **注意**：终止操作不可逆，请谨慎操作。
