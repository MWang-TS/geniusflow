# 知识库管理

GeniusFlow 支持两种类型的知识库，分别适用于不同的使用场景：

| 类型 | 用途 |
|------|------|
| **RAG 知识库** | 上传文档，AI 通过向量检索精准召回相关内容 |
| **Wiki 知识库** | 结构化知识整理，自动解析实体关系，生成知识图谱 |

---

## 一、知识库列表

进入 **知识库**，查看所有已创建的知识库。

- 按类型筛选：RAG / Wiki
- 显示文档数量和处理状态统计

### 创建知识库

1. 点击 **「新建知识库」**
2. 填写：
   - **名称**：知识库名称
   - **类型**：RAG 或 Wiki
   - **分类**：说明书 / 会议纪要 / 报告手册 / 规范 / 其他
   - **描述**：简要描述知识库内容
3. 点击确认创建

### 管理知识库

- **重命名**：点击知识库右侧的重命名按钮
- **删除**：点击删除按钮，确认后不可恢复

---

## 二、RAG 知识库

RAG（检索增强生成）知识库适合存放**非结构化文档**，系统会将文档切分为文本块并向量化，AI 问答时自动召回最相关的内容。

### 2.1 上传文档

进入 RAG 知识库详情页，有两种添加文档方式：

**方式一：上传文件**
1. 点击上传区域或直接**拖拽文件**到上传框
2. 支持格式：PDF、Word（.docx/.doc）、TXT、Markdown 等
3. 上传后系统自动开始解析

**方式二：直接输入文本**
1. 点击 **「文本输入」** 选项卡
2. 填写文档标题和正文内容
3. 点击保存

### 2.2 文档处理状态

| 状态 | 含义 |
|------|------|
| 待解析 | 文件已上传，等待处理 |
| 解析中 | 正在切分和向量化 |
| 已完成 | 处理成功，可用于检索 |
| 失败 | 处理出错，可重新上传 |

### 2.3 RAG 参数配置

点击 **「配置」** 选项卡，可调整检索参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **分块大小（chunkSize）** | 每个文本块的字符数 | 1000 |
| **分块重叠（chunkOverlap）** | 相邻文本块的重叠字符数，避免内容截断 | 200 |
| **检索数量（topK）** | 每次检索返回的最相关块数 | 5 |
| **相似度阈值（similarityThreshold）** | 低于此阈值的结果不返回（0~1） | 0.75 |

> **建议**：长文档适当增大 chunkSize；对精准度要求高时提高 similarityThreshold。

## 三、Wiki 知识库

Wiki 知识库适合整理**结构化知识**，系统会自动解析文档中的实体、概念和关系，构建知识图谱，支持更深层的语义理解。

### 3.1 上传 Wiki 源文件

1. 进入 Wiki 知识库详情页，切换到 **「来源」** 选项卡
2. 上传 Wiki 源文件，支持 Markdown、HTML 等格式
3. 点击 **「解析」** 开始处理

**来源处理状态：**

| 状态 | 含义 |
|------|------|
| 待解析 | 已上传，等待处理 |
| 解析中 | 正在提取结构和实体 |
| 已完成 | 解析成功，已生成页面 |
| 失败 | 解析失败，可重试 |

如需重新解析，点击文件右侧的 **「重新解析」** 按钮。

### 3.2 Wiki 页面管理

切换到 **「页面」** 选项卡，查看自动解析生成的知识页面：

**页面类型：**

| 类型 | 说明 |
|------|------|
| 目录 | 知识分类目录 |
| 概念 | 抽象概念定义 |
| 实体 | 具体事物、人物、组织 |
| 来源 | 对应原始文档的页面 |
| 日志 | 时间线相关记录 |

点击页面可预览渲染内容，也可以**编辑页面属性**（标题、类型、关键词等）。

**编译状态：**

| 状态 | 含义 |
|------|------|
| 待编译 | 等待知识图谱编译 |
| 编译中 | 正在提取三元组关系 |
| 已完成 | 编译完成，已纳入知识图谱 |
| 失败 | 编译失败 |

### 3.3 知识图谱

切换到 **「图谱」** 选项卡，以力导向图可视化展示实体之间的关系网络：

- **节点**：知识实体（人物、概念、组织等）
- **边**：实体之间的关系（属于、属性、关联等）
- 支持拖拽、缩放交互

---

## 四、知识库与 AI 功能的联动

知识库创建后，可以在以下场景中使用：

| 场景 | 使用方式 |
|------|---------|
| **AI 技能助手** | 对话时选择知识库，AI 基于库内内容回答 |
| **流程节点 AI 辅助** | 在节点配置中挂载知识库，执行任务时 AI 自动召回相关文档 |
| **开放平台 API** | 创建 API 密钥时关联知识库，供第三方系统调用 |
